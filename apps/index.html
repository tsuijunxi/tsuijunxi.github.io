Lensori

用自然语言和参考图片，重新找到你的照片。

查看功能 App Store

它解决什么问题

Lensori 帮你在庞大的照片库里重新找到那些记忆里的画面：不需要记住准确日期、相册或文件名，也可以用一张照片作为参考，找到相似照片。

核心功能

  • 用自然语言、场景、时间或地点搜索照片。
  • 用一张参考图片查找相似照片。
  • 在专注的照片浏览器中查看搜索结果。
  • 升级 Pro 后创建 3D Memory 片段。

技术亮点

  • 端侧 CLIP 视觉检索：在本地为照片库建立索引并完成搜索，不需要账号，也不会上传到服务器。
  • 端侧翻译模型：支持将中文和日文查询翻译成英文，再与本地照片 embedding 匹配。
  • 端侧深度模型：为照片生成 3D Memory 视频。
