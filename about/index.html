关于我

我是凌云，现在在上海做 iOS 和 C/C++ 开发。

我在写什么

  • 编译器、解释器与 JavaScriptCore

  • 图形、几何算法与跨平台工程实践

代表文章

  • 连续圆角的艺术 - 从曲率连续性出发，分析并复现 Apple Continuous Corner。
  • 从源码看 C++ 异常 - 沿着 libc++abi、libunwind 和 Itanium C++ ABI 追踪异常处理。
  • 深入理解 Objective-C Block 与 C++ Lambda - 对比两种闭包的捕获语义和内存模型。
  • 跨平台渲染引擎之 Markdown - 从 C++ 解析到 iOS 与 Android 平台适配的 Native 渲染方案。
  • 聊聊 iOS 富文本的流式渲染 - 面向大模型回复的流式排版、LaTeX、TTS 和性能取舍。
  • 如何用 Trampoline Hook 重定向 Objective-C Block - 使用 trampoline 机制实现 Block 调用的拦截与恢复。
